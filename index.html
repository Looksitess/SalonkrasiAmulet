Справді сімейний формат

Пропонуємо одночасні процедури для всієї родини: комплексний догляд для жінок, стильні стрижки для чоловіків та бережливий сервіс для дітей.

Безпека та Стерильність

Суворо дотримуємося медичних стандартів дезінфекції. Трьохетапна стерилізація інструментів гарантує вашу абсолютну безпеку.

Зручна локація

Знаходимося у Святошинському районі на вулиці Осіння, 33. Всього кілька хвилин пішки від станції метро Академмістечко.
