# Инструкции для Codex — Salon SaaS

В репозитории есть `AGENTS.md` и пять специализированных скиллов в `.agents/skills/`.

## Скиллы
- `full-stack-developer` — клиентская и серверная разработка.
- `supabase-database-architect` — схема PostgreSQL, миграции и RLS.
- `cybersecurity-auditor` — проверка безопасности.
- `ui-ux-designer` — интерфейс, запись и админка.
- `saas-platform-architect` — multi-tenant архитектура и выпуск SaaS.

## Как использовать
Открой репозиторий в Codex. Попроси прочитать `AGENTS.md` и скиллы, затем выполнить аудит. Для начала требуй только отчёт и план; не разрешай сразу менять production-базу.

## Безопасность
Никогда не добавляй в репозиторий service-role/secret keys, пароли, токены приглашений или сброса пароля. Не применяй миграции к production без резервной копии и отдельного анализа. Добавление этих инструкций не означает, что сайт уже прошёл аудит или готов к коммерческой продаже.
