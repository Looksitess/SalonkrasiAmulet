# Amulet — сайт онлайн-запису салону краси

## Що є в проєкті
- Адаптивний сайт для телефону, планшета й комп’ютера.
- Каталог послуг і форма онлайн-запису.
- Вибір майстра, дати й доступного часу через Supabase.
- Адмін-панель: перегляд і пошук записів, фільтри, календар, статистика, керування майстрами та графіками.
- Браузерні сповіщення про нові заявки, коли адмін-панель відкрита.
- Сезонна тема за місяцем року.
- Галерея з переглядом фото та розділ із фото фасаду.

## Посилання
- Сайт: https://looksitess.github.io/SalonkrasiAmulet/
- Адмін-панель: https://looksitess.github.io/SalonkrasiAmulet/admin/
- Репозиторій: https://github.com/Looksitess/SalonkrasiAmulet

## Передача проєкта покупателю
1. Сначала договоритесь, что именно продаётся: исходный код, настройка сайта, домен, база данных или обслуживание.
2. Перед передачей замените название, телефон, адрес, услуги, цены, карту и все фото на материалы, на которые покупатель имеет права.
3. Передавайте доступ к GitHub и Supabase только через безопасную смену владельца/приглашение участника. Не отправляйте пароли и ключи в переписке.
4. Проверьте RLS-политики Supabase, права на таблицы и Edge Functions. Публичный ключ Supabase допустим только при корректных RLS-политиках; service-role ключ никогда нельзя помещать в браузерный код.
5. Создайте резервную копию базы данных и сохраните список настроек окружения без секретных значений.
6. Проверьте тестовую запись, занятый слот, отмену записи, вход администратора и вход мастера.
7. Передайте покупателю инструкцию по изменению контента, цен, расписания, пользователей и настройке уведомлений.

## Важные ограничения
- Уведомления браузера приходят только если разрешены браузером и админ-панель открыта. Для уведомлений при закрытом сайте нужен отдельный серверный механизм/push.
- Для работы онлайн-записи нужны действующий проект Supabase, корректные таблицы/RPC/Edge Functions и безопасные политики доступа.
- Фото фасада подключено по относительному пути `images/salon-facade.jpg`. Убедитесь, что файл выглядит правильно на опубликованном сайте и что покупатель имеет право использовать его.
- Не продавайте реальные клиентские записи или личные данные. Для демонстрации используйте тестовые данные.
- Это руководство не заменяет полноценный аудит безопасности и проверку договора передачи прав.
